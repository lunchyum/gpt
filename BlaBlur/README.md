# 블라블러 — 개인용 iOS 앱

SwiftUI / UIKit / Core Image / Photos / SafariServices로 만든 iOS 16 이상용 프로젝트입니다. 외부 패키지나 서버 설정 없이 Xcode에서 엽니다.

## iPhone에 설치

1. Mac에서 ZIP을 풀고 `BlaBlur.xcodeproj`를 엽니다.
2. Xcode Settings → Accounts에서 Apple 계정을 추가합니다.
3. 프로젝트의 **BlaBlur target → Signing & Capabilities**에서 Automatically manage signing을 켜고 자신의 Team을 선택합니다. Bundle Identifier를 `com.본인고유이름.BlaBlur`처럼 고유하게 바꿉니다.
4. iPhone을 Mac에 연결하고 실행 대상으로 선택합니다. 기기가 요구하면 개발자 모드 및 개발자 앱 신뢰를 설정합니다.
5. ▶ Run으로 빌드·설치합니다. 무료 Personal Team은 서명 만료 시 Xcode에서 재설치해야 할 수 있습니다.

서명된 IPA는 포함하지 않습니다. 본인의 Mac/Xcode와 Apple 계정에서 서명해야 합니다. 생성 환경에는 Xcode 및 iOS SDK가 없어 실제 컴파일·시뮬레이터·실기기 테스트는 수행하지 못했습니다.

## 동작

1. 다른 앱에서 텍스트를 복사하고 블라블러를 엽니다.
2. iOS가 요청하면 붙여넣기를 허용합니다. 거절했거나 내용이 없으면 시스템 붙여넣기 버튼으로 다시 진행할 수 있습니다.
3. 아래 세 문구와 정확히 일치하는 모든 부분은 굵고 선명하게, 나머지는 6pt 가우시안 블러로 이미지화합니다.
   - 오늘의 나는 충분히 몰입했는가?
   - 오늘 좋았거나 안좋았던 거 하나 돌아보기:
   - 내일의 내게 들려주고 싶은 말은 무엇인가?
4. 기기의 달력·시간대 기준 어제 날짜를 이미지 상단에 표시합니다.
5. 사진 **추가 전용** 권한을 요청하고 PNG 이미지를 저장합니다. 기존 사진을 읽지 않습니다.
6. 저장 성공 후 `https://odyssey.zstrit.com`을 앱 내부 Safari 화면으로 엽니다. 완료 버튼으로 돌아옵니다. 웹사이트 자동 업로드는 하지 않습니다.

앱을 다시 활성화하면 클립보드가 바뀐 경우 처리합니다. 웹 화면이 열려 있으면 자동 처리를 보류하므로 새 글은 웹 화면을 닫고 ‘붙여넣기’로 처리하세요. 같은 날짜·동일 내용의 저장 이력은 최근 120건의 SHA-256 해시만 보관해 자동 중복 저장을 피합니다. ‘사진에 저장’은 의도적인 재저장을 허용합니다. 사진을 직접 지운 경우에도 재저장 버튼을 사용하세요.

저장 실패 시 웹사이트로 자동 이동하지 않습니다. 권한을 허용한 뒤 다시 저장하거나 ‘Odyssey 열기’를 사용할 수 있습니다. 클립보드 원문은 파일·로그·설정에 기록하지 않으며 사이트에 전달하지 않습니다.

## 출력 및 변경

- 이미지 너비 780px, 기본 높이 960px. 긴 글은 세로로 늘려 본문이 잘리지 않도록 합니다. 최대 10,000자 또는 12,000px 높이를 넘으면 나누어 처리하라는 안내를 표시합니다.
- 질문 목록: `BlaBlur/BlurRenderer.swift`의 `phrases`.
- 웹 주소: `BlaBlur/ContentView.swift`의 `OdysseyBrowser`.
- 블러 강도: `BlurRenderer.swift`의 `kCIInputRadiusKey` (현재 2배 렌더링에서 12px).
- 블러는 시각적 흐림 효과입니다. 글의 길이나 윤곽까지 숨기는 완전한 비식별화가 필요하면 불투명 가림 방식으로 바꾸세요.

## 확인

Xcode에서 Product → Test (⌘U)를 실행하면 반복 문구, 이모지 앞뒤 UTF-16 범위, 정확한 문구 매칭, 연도 경계의 어제 날짜, 이미지 생성 및 입력 제한 테스트를 실행합니다.

기기에서 확인할 항목:

- 최초 붙여넣기 허용/거절 및 버튼 재시도
- 사진 권한 허용/거절 후 재저장
- 세 질문·한국어 답변·이모지·줄바꿈·HTML 문자열의 출력
- 긴 글의 마지막 줄까지 저장되는지, 저장된 사진에서 답변이 흐린지
- 같은 내용으로 재실행할 때 자동 중복 저장되지 않는지
- 저장 성공 후 Odyssey 표시와 실제 사이트 로그인, 네트워크 오류 시 완료 버튼으로 복귀

웹 검색 도구에서는 해당 사이트 내용을 불러올 수 없었으므로 사이트 가용성 및 로그인 동작은 실기기에서 확인해야 합니다.
